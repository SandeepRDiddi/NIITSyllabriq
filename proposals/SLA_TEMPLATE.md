# SLA Template Notes

This is a starting point for commercial discussions and not legal advice.

## Suggested Service Scope

- web application availability
- API availability
- database availability
- document storage availability
- review workflow accessibility

## Suggested Exclusions

- customer-side internet failures
- third-party identity outages
- customer-managed local model outages
- abuse, malware, or unsupported usage patterns
- scheduled maintenance windows

## Suggested Metrics

- uptime percentage
- P1 / P2 / P3 response time
- backup retention
- restore testing frequency
- RPO / RTO targets for enterprise tier
